Many of the problems on LeetCode have "given" code snippets that I have to work with. More often than not, their variable naming conventions are **awful**. So, if you see me using a variable just called "x" or "i1, i2, i3" know that I'm using what was given to me and didn't have a choice.

## Another Thing to Note about this Repository
I will **NOT** be creating seperate branches for every problem. I know that it's 'bad practice' to commit directly to the main branch, but it will never be more than 1 file changing at a time. Maybe, I'll work on one or two problems at once at some point, but the commit messages would still clearly state which file was updated when.

There is just not benefit to branching every time, in this repo's case.
